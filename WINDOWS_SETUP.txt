CYBERTRADE — ONE CLICK (No Anaconda Prompt needed) + Miniconda Setup
======================================================================
Env: cybertrade (normal Miniconda only)

YOU SAID: "i don't wanna open it with anaconda prompt just a click"
SOLUTION: Double-click CYBERTRADE.bat — that's it.

ONE-CLICK START (Just double-click):
-------------------------------------
1. Install Miniconda ONCE (if not installed):
   https://repo.anaconda.com/miniconda/Miniconda3-latest-Windows-x86_64.exe
   Run installer -> Just Me -> keep defaults (no need to check Add to PATH)

2. Double-click CYBERTRADE.bat in Explorer
   - Auto-finds Miniconda in 9 locations even if conda not in PATH
   - If env cybertrade doesn't exist, creates it (first time 1-2 min)
   - Activates env by setting PATH directly (no conda activate needed)
   - Runs python -m cybertrade doctor (10/10 checks)
   - Runs web HUD at http://localhost:8899 and opens browser

Other one-click:
  CYBERTRADE_GUI.bat -> same but desktop GUI
  click_to_run.bat   -> same as CYBERTRADE.bat (simple name)

That's it — ONE CLICK, no Anaconda Prompt, no typing.

IF DOUBLE-CLICK FLASHES AND CLOSES:
  Open CMD, cd to folder, run CYBERTRADE.bat to see error
  Or right-click -> Edit to see what it does (it has pause at end)

IF SAYS "Miniconda NOT found":
  Install Miniconda from link above, then double-click CYBERTRADE.bat again

IF ENV CREATION FAILS:
  In Anaconda Prompt:
    conda clean --all
    conda env remove -n cybertrade
  Then double-click CYBERTRADE.bat again

NORMAL MINICONDA SETUP (if you prefer Anaconda Prompt):
--------------------------------------------------------
1. Open Anaconda Prompt from Start Menu (search "Anaconda Prompt")
2. cd /d C:\path\to\CYBERTRADE
3. conda env create -f environment.yml
4. conda activate cybertrade
5. python -m cybertrade doctor

DAILY USE (after one-click setup):
----------------------------------
Just double-click CYBERTRADE.bat any time — it will use existing env and run.

Or in Anaconda Prompt:
  conda activate cybertrade
  python -m cybertrade run
  python -m cybertrade backtest --bars 200

FIX FOR: [!] conda not found in PATH
-------------------------------------
If you ran setup_conda.bat in normal CMD and saw:
  [!] conda not found in PATH

This is NORMAL Miniconda — it doesn't add to PATH in normal CMD.
Anaconda Prompt has conda in PATH automatically.

FIX 1 (Recommended): Use Anaconda Prompt
  Windows key -> type Anaconda Prompt -> open -> cd to folder -> conda env create -f environment.yml

FIX 2 (One-click, no Anaconda Prompt):
  Double-click CYBERTRADE.bat — new version auto-searches Miniconda even if not in PATH

FIX 3: Run fix_conda_path.bat
  Double-click fix_conda_path.bat — finds Miniconda and adds to PATH for session

FIX 4: Make conda work in normal CMD forever:
  In Anaconda Prompt:
    conda init cmd.exe
    conda init powershell
  Restart CMD/PowerShell
